MCP Doctor inspects tools, resources, prompts, schemas, timeouts, and baseline identity before a manifest becomes somebody else’s debugging afternoon.

Four checks, one calmer handoff

Shapeis the manifest parseable?
Explaincan a human understand each tool?
Bounddoes it declare a positive timeout?
Driftdoes it still match its baseline?
Browser model: the manifest tree and findings below are synthetic page state. No MCP server is contacted, and no provider behavior is inferred. Run the CLI commands at the bottom against an actual JSON file when you want evidence.

cd mcp-doctor
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install .
mcp-doctor check examples/valid-server.json
mcp-doctor check examples/invalid-server.json
cat examples/valid-server.json | mcp-doctor check - --strict --json
mcp-doctor check examples/valid-server.json --baseline examples/valid-server.json --json
