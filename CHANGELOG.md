# Changelog

## 0.1.0 — 2026-09-30

Initial public release.

- Validate common `mcpServers` and `servers` JSON configuration files.
- Probe an MCP stdio server with `initialize` and optional `tools/list` requests.
- Provide a dependency-free runtime and JSON output for automation.
- Include an installable package, built-in demo, tests, and GitHub Actions CI.
